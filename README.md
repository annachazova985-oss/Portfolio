Одностраничный сайт студии дизайна интерьеров «Среда» в Перми. Портфолио проектов, калькулятор стоимости, мудборд, форма записи на консультацию, версия для слабовидящих.

## 🔗 Живая версия

**[https://annachazova985-oss.github.io/Portfolio/](https://annachazova985-oss.github.io/Portfolio/)**

## 📋 Что есть на сайте

- **Портфолио проектов** — карусель с карточками, лайтбокс с галереей фотографий и описанием каждого проекта.
- **Калькулятор стоимости** — выбор пакета дизайн-проекта и площади, автоматический расчёт цены.
- **Мудборд** — интерактивный сбор цветов, фактур и настроения для будущего интерьера с отправкой дизайнеру.
- **Форма записи на консультацию** — валидация полей, маска телефона, выбор даты и времени, защита от спама (honeypot + лимит отправок).
- **Версия для слабовидящих** — размер шрифта, межбуквенный интервал, 5 цветовых схем, режимы изображений (цвет / ч-б / скрыть).
- **Адаптивная вёрстка** — корректно работает на телефонах, планшетах и десктопах.
- **Доступность** — навигация с клавиатуры, focus trap в модалках, aria-атрибуты.

## 🛠 Стек
