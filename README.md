## 📋 Что есть на сайте

- **Портфолио проектов** — карусель с карточками, лайтбокс с галереей фотографий и описанием каждого проекта. Фото открываются на весь экран с навигацией стрелками и клавиатурой.
- **Свайп в галерее** — на телефоне фотографии в проекте листаются пальцем (влево/вправо), как в галерее телефона. Кнопки ‹ › также работают.
- **Калькулятор стоимости** — выбор пакета дизайн-проекта и площади, автоматический расчёт цены. Таблица пакетов адаптирована для мобильных — без горизонтального скролла, с кликабельными заголовками.
- **Мудборд** — интерактивный сбор цветов, фактур и настроения для будущего интерьера с отправкой дизайнеру. Выбор сохраняется в браузере (localStorage) — не теряется при обновлении страницы.
- **Форма записи на консультацию** — валидация полей, маска телефона, выбор даты и времени, защита от спама, аккуратные сообщения об ошибках.
- **Версия для слабовидящих** — размер шрифта, межбуквенный интервал, 5 цветовых схем, режимы изображений.
- **Адаптивная вёрстка** — корректно работает на телефонах, планшетах и десктопах. На мобильном — отдельная упрощённая шапка с иконкой звонка. Мобильное меню содержит быстрые ссылки на соцсети (Telegram, ВК, MAX).
- **Кастомная страница 404** — вместо стандартной страницы GitHub Pages пользователь видит брендированную с навигацией.
- **Доступность** — навигация с клавиатуры, focus trap в модалках, aria-атрибуты, поддержка `prefers-reduced-motion`.
- **SEO-база** — карта сайта (`sitemap.xml`) с автоматическим обновлением через GitHub Actions, правила для поисковиков (`robots.txt`), правильные мета-теги Open Graph и Twitter Card, микроразметка Schema.org (`HomeAndConstructionBusiness` + `Offer` + `author`), canonical URL, гео-метки.
- **Анимации** — плавное появление фото при загрузке, плавное появление секций при скролле, hover-эффекты на карточках.
- **Оптимизация скорости** — PageSpeed 100/100 на десктопе, 99/100 на мобильных. Локальные шрифты (без Google Fonts), изображения в WebP, ленивая загрузка.
- **Автоматизация** — GitHub Actions автоматически обновляет `sitemap.xml` при изменении картинок или скриптов.

## 📁 Структура проекта

**Portfolio/** — корневая папка проекта

- **index.html** — разметка страницы
- **style.css** — все стили
- **script.js** — весь JavaScript
- **404.html** — кастомная страница «не найдено»
- **robots.txt** — правила индексации для поисковых систем
- **sitemap.xml** — карта сайта (обновляется автоматически)
- **site.webmanifest** — PWA-манифест
- **README.md** — этот файл
- **SEO-ИНСТРУКЦИЯ.md** — пошаговая инструкция для владельца сайта
- **ROADMAP.md** — план развития сайта
- **scripts/** — скрипты автоматизации
  - `generate-sitemap.js` — генератор карты сайта
  - `image-titles.json` — человекочитаемые подписи к фото
- **.github/workflows/** — конфигурация GitHub Actions
  - `update-sitemap.yml` — автообновление sitemap
- **images/** — изображения проектов и иконки
  - `hero.webp` — фото для hero-секции
  - `about.webp` — фото для секции «О студии»
  - `img-01.png` — логотип
  - `img-04.webp` … `img-09.webp` — фактуры для мудборда
  - `project-XX-YY.webp` — фотографии проектов (XX — номер проекта, YY — номер фото внутри проекта)

## 🔍 SEO и индексация

Сайт подготовлен к индексации в поисковых системах:

- **`robots.txt`** — разрешает индексацию и указывает на карту сайта.
- **`sitemap.xml`** — карта сайта с автоматическим обновлением при добавлении новых фото.
- **Микроразметка Schema.org** — тип `HomeAndConstructionBusiness` с перечнем услуг, цен и автором сайта.
- **`<meta name="description">`** — описание для поисковой выдачи.
- **Open Graph / Twitter Card** — корректные превью при отправке ссылки в соцсетях и мессенджерах.
- **Canonical URL** — защита от дублей.
- **Гео-метки** — для локального SEO (Пермь).
- **Семантические заголовки** — h1, h2, h3 по иерархии.

Что нужно сделать **владельцу сайта после передачи** — см. файл [`SEO-ИНСТРУКЦИЯ.md`](./SEO-ИНСТРУКЦИЯ.md).
