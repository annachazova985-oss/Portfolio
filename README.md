Одностраничный сайт студии дизайна интерьеров «Среда» в Перми. Портфолио проектов, калькулятор стоимости, мудборд, форма записи на консультацию, версия для слабовидящих.

## 🔗 Живая версия

**[https://annachazova985-oss.github.io/Portfolio/](https://annachazova985-oss.github.io/Portfolio/)**

## 📋 Что есть на сайте

- **Портфолио проектов** — карусель с карточками, лайтбокс с галереей фотографий и описанием каждого проекта.
- **Калькулятор стоимости** — выбор пакета дизайн-проекта и площади, автоматический расчёт цены.
- **Мудборд** — интерактивный сбор цветов, фактур и настроения для будущего интерьера с отправкой дизайнеру.
- **Форма записи на консультацию** — валидация полей, маска телефона, выбор даты и времени, защита от спама.
- **Версия для слабовидящих** — размер шрифта, межбуквенный интервал, 5 цветовых схем, режимы изображений.
- **Адаптивная вёрстка** — корректно работает на телефонах, планшетах и десктопах.
- **Доступность** — навигация с клавиатуры, focus trap в модалках, aria-атрибуты.

## 🛠 Стек

- **images/** — изображения проектов и иконки
  - img-01.png — логотип
  - img-02.jpg — фото для hero-секции
  - img-03.jpg — фото для секции «О студии»

  - img-10 … 17.jpg — фотографии проектов
- **README.md** — этот файл

## 🚀 Как запустить локально

1. Скачай репозиторий командой: `git clone https://github.com/annachazova985-oss/Portfolio.git`
2. Открой папку Portfolio.
3. Запусти index.html в браузере — двойным кликом.

Или используй локальный сервер: `python -m http.server 8000` и открой [http://localhost:8000](http://localhost:8000).
