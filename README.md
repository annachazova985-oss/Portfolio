**[https://annachazova985-oss.github.io/Portfolio/](https://annachazova985-oss.github.io/Portfolio/)**

## 📋 Что есть на сайте

- **Портфолио проектов** — карусель с карточками, лайтбокс с галереей фотографий и описанием каждого проекта.
- **Свайп в галерее** — на телефоне фотографии в проекте листаются пальцем (влево/вправо), как в галерее телефона. Кнопки ‹ › также работают.
- **Калькулятор стоимости** — выбор пакета дизайн-проекта и площади, автоматический расчёт цены.
- **Мудборд** — интерактивный сбор цветов, фактур и настроения для будущего интерьера с отправкой дизайнеру.
- **Форма записи на консультацию** — валидация полей, маска телефона, выбор даты и времени, защита от спама, аккуратные сообщения об ошибках.
- **Версия для слабовидящих** — размер шрифта, межбуквенный интервал, 5 цветовых схем, режимы изображений.
- **Адаптивная вёрстка** — корректно работает на телефонах, планшетах и десктопах. На мобильном — отдельная упрощённая шапка с иконкой звонка.
- **Доступность** — навигация с клавиатуры, focus trap в модалках, aria-атрибуты, поддержка `prefers-reduced-motion`.
- **SEO-база** — карта сайта (`sitemap.xml`), правила для поисковиков (`robots.txt`), правильные мета-теги Open Graph и Twitter Card.
- **Анимации** — плавное появление фото при загрузке, плавное появление секций при скролле, hover-эффекты на карточках.

## 📁 Структура проекта

**Portfolio/** — корневая папка проекта

- **index.html** — разметка страницы
- **style.css** — все стили
- **script.js** — весь JavaScript
- **robots.txt** — правила индексации для поисковых систем
- **sitemap.xml** — карта сайта для поисковых систем
- **SEO-ИНСТРУКЦИЯ.md** — пошаговая инструкция для владельца сайта (что делать после получения сайта)
- **images/** — изображения проектов и иконки
  - img-01.png — логотип
  - img-02.jpg — фото для hero-секции
  - img-03.jpg — фото для секции «О студии»
  - img-04 … 09.jpg — фактуры для мудборда
  - img-10 … 17.jpg — фотографии проектов
- **README.md** — этот файл

> **Примечание.** Часть изображений (логотип, hero-фото, фото «О студии», фактуры мудборда) сейчас встроены в `index.html` как base64-строки — так было задумано изначально для скорости разработки. В планах — вынести их в отдельные файлы в папке `images/` для ускорения загрузки (см. раздел «В планах»).

## 🔍 SEO и индексация

Сайт подготовлен к индексации в поисковых системах:

- **`robots.txt`** — разрешает индексацию и указывает на карту сайта.
- **`sitemap.xml`** — карта сайта с датой обновления.
- **`<meta name="description">`** — описание для поисковой выдачи.
- **Open Graph / Twitter Card** — корректные превью при отправке ссылки в соцсетях и мессенджерах.
- **Семантические заголовки** — h1, h2, h3 по иерархии.

Что нужно сделать **владельцу сайта после передачи** (регистрация в поисковых системах, Метрика, домен) — см. файл [`SEO-ИНСТРУКЦИЯ.md`](./SEO-ИНСТРУКЦИЯ.md).

## 🚀 Как запустить локально

1. Скачай репозиторий командой: `git clone https://github.com/annachazova985-oss/Portfolio.git`
2. Открой папку Portfolio.
3. Запусти index.html в браузере — двойным кликом.

Или используй локальный сервер: `python -m http.server 8000` и открой [http://localhost:8000](http://localhost:8000).
